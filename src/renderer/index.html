キーボードショートカット & ジェスチャー

  • 右ドラッグ : マウスジェスチャー（タブ切替・追加・削除・連続スクロール等）
  • Ctrl + T / W / Shift+T : 新しいタブ / タブを閉じる / 閉じたタブを復元
  • Ctrl + Tab / Shift+Tab : 次 / 前のタブへ切り替え
  • Ctrl + K : サービス カタログを開く
  • Ctrl + 1 〜 9 : 登録済みサービスを素早く切り替え
  • Ctrl + Shift + L : プライバシーロック（全画面即時隠蔽）

マウスジェスチャー設定

右ボタンを押したまま上下左右にドラッグして離すと操作を実行。スクロール割り当て時はドラッグ中リアルタイムに進行します。

割当先: ← (左)
1方向（← → ↑ ↓）
2方向（直角に1回曲げる 8通り · ドラッグで入替可能）
手ぶれ補正（開始時の無視距離）: 4px
※ 動かさず普通に右クリックすると従来の右クリックメニューが開きます。ドラッグ中に Esc または左クリックで中止できます。
