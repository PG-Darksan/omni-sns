キーボードショートカット & ジェスチャー

  • 右ドラッグ : マウスジェスチャー（タブ切替・Ctrl+クリック・アカウント切替・連続スクロール等）
  • Ctrl + クリック / 中クリック : 同一アカウントのログイン状態を保ったままリンクを別タブで開く
  • Ctrl + L : アドレスバーにフォーカス（Enter で移動 / Alt+Enter で別タブで開く）
  • Ctrl + + / - / 0 : 表示倍率の拡大 / 縮小 / 100%リセット
  • Ctrl + Alt + 1 〜 9 / ← → : 同一SNS内のアカウントを瞬時に切り替え
  • Ctrl + T / W / Shift+T : 新しいタブ / タブを閉じる / 閉じたタブを復元
  • Ctrl + Tab / Shift+Tab : 次 / 前のタブへ切り替え
  • Ctrl + K : サービス カタログを開く
  • Ctrl + 1 〜 9 : 登録済みSNSを素早く切り替え
